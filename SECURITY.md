# Security Policy

## Supported Versions

The following branches are currently supported with security updates:

| Branch                  | Supported                 |
| ----------------------- | ------------------------- |
| main                    | ✅ Yes                    |
| staging                 | ⚠️ Limited (testing only) |
| test / feature branches | ❌ No                     |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please **do NOT** open a public GitHub issue.

Instead, report it responsibly using one of the following options:

- 📩 **GitHub Security Advisories**  
  Go to:  
  **Repository → Security → Advisories → New draft advisory**

- 📧 **Email** (optional fallback):  
  `security@nexl.dev`  
  _(placeholder email is acceptable for personal projects)_

---

## Response Timeline

- Initial response: **within 48 hours**
- Fix / mitigation plan: **as soon as possible**
- Public disclosure: **after fix is released**

---

Thank you for helping keep this project secure 🙏
